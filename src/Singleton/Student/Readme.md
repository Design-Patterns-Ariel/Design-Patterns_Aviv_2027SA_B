# אתגר Java – מערכת לניהול תורים

לפניכם מערכת לניהול תורים המשרתת את הספרייה ואת המזכירות במכללה.

הריצו את התוכנית ובחנו את התוצאה המתקבלת.

**הפלט הנוכחי:**

```
Office: 1
Library: 1
Office: 2
Library: 2
Office: 3
```

כפי שניתן לראות, כל מחלקה מנהלת את מספרי התורים בנפרד.

**המשימה שלכם:**

שנו את הקוד כך שיעמוד בדרישות הבאות:

- בכל התוכנית יהיה לכל היותר אובייקט אחד מסוג `TicketManager`.
- כל המחלקות יוכלו לגשת באופן עצמאי לאותו אובייקט.
- לא ניתן יהיה ליצור אובייקט נוסף מסוג `TicketManager` מחוץ למחלקה.
- המשתנה `nextNumber` יישאר משתנה של האובייקט ולא יהפוך למשתנה סטטי.
- אין לשנות את הקוד במחלקה `Main`.

**הפלט הרצוי:**

```
Office: 1
Library: 2
Office: 3
Library: 4
Office: 5
```

זמן לביצוע: 15 דקות.
